# Asad Ali: motion portfolio

React + Vite + TypeScript + Tailwind CSS + GSAP + Framer Motion + hls.js.

## Run it on your PC
    npm install
    npm run dev

## Live site
https://asad778-code.github.io/

Repository: https://github.com/Asad778-code/Asad778-code.github.io
Every `git push` to `main` republishes the site automatically.

## Edit content
All text, links, projects, services and stats live in `src/data.ts`.
Images are in `public/img`.
