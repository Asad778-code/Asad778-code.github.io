# Asad Ali: motion portfolio

React + Vite + TypeScript + Tailwind CSS + GSAP + Framer Motion + hls.js.

## Run it on your PC
    npm install
    npm run dev

## Put it online (free, GitHub Pages)
1. On github.com, create a new PUBLIC repository (for example `portfolio`). Do not add a README.
2. In this folder run:

       git remote add origin https://github.com/YOUR-USERNAME/portfolio.git
       git push -u origin main

3. On GitHub open the repository: Settings > Pages > Source: **GitHub Actions**.
4. Open the Actions tab and wait for "Deploy to GitHub Pages" to go green.
   The site is then live at https://YOUR-USERNAME.github.io/portfolio/

Every later `git push` republishes the site automatically.

## Edit content
All text, links, projects, services and stats live in `src/data.ts`.
Images are in `public/img`.
